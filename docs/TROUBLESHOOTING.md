# 常见问题

## 导出的淡出帧带白点

先检查 PNG 的 RGB 和 Alpha。在实际烟雾合成中，8 bpc 工程的交叉淡入淡出曾在 **Alpha 为 0 的像素中产生高亮 RGB 残留**。正确使用 Alpha 时这些点完全透明，仅查看 RGB 时则出现白点。对同一帧进行 16 bpc / 32 bpc 重渲染，已验证可以消除该案例的高亮残留。

处理步骤：

1. 打开 AE「文件 → 项目设置」，在颜色设置中把深度设为 **16 位/通道（16 bpc）**。
2. 重新生成并导出图集。修改工程位深不会修复已经输出的 PNG。
3. 输出仍使用 **RGB + Alpha / Straight（直接、无蒙版）**。
4. 在下游材质中正确使用 Alpha，并分别检查仅 RGB 与合成后的外观。

工程计算位深与 PNG 输出位深是两个设置。即使最终文件是 8 位/通道，提高工程计算精度仍可改善结果。[Adobe：选择颜色深度](https://www.adobe.com/us/learn/after-effects/web/choose-the-right-color-depth)。这不是所有白点问题的通用诊断；如果白点本身具有明显 Alpha，还应检查源素材、效果及混合方式。插件不会自行修改工程位深。

## 提示没有可用的透明 PNG 模板

模板只需在当前 AE 用户环境创建一次：

1. 把任意合成加入渲染队列；此时不需要开始渲染。
2. 单击队列中「输出模块」后面的设置名称，打开输出模块设置。
3. 格式选 **PNG 序列**，通道选 **RGB + Alpha**，颜色选 **Straight / Unmatted（直接／无蒙版）**。
4. 关闭调整大小和裁剪，保存设置。
5. 在输出模块的模板管理入口把此设置保存为模板，命名为 **SpriteSheet_PNG_RGBA**。
6. 删除刚才仅用于设置模板的队列项，回到工具填写相同的备用模板名称并重新导出。

插件会检查当前设置、备用名称以及名称含 PNG 的模板。AE 输出格式、通道和颜色字段可能是脚本只读项，因此插件不能保证从零自动创建此模板。导出还需在 AE 首选项中启用「允许脚本写入文件和访问网络」。

## 点击预计算后图像没有变化

检测完成后，以及参数提交时，预览已经自动更新；参数未变时再次计算会得到同样的结果。按钮会滚动到结果并显示更新时间。排列示意位于全部参数下方，蓝色块仅表示内容区域，不显示烟雾图像。

## 内容检测耗时或无法立刻取消

新版透明度检测先制作临时阈值遮罩，再用区域查询查找边界，避免低透明度烟雾的递归扫描。每帧之间会交回 AE 控制权，但单帧渲染或表达式求值仍是同步的；当前帧未完成时取消不能立即响应。降低检测密度、缩小检测工作区，或先检测一个源帧，可以帮助判断源合成的渲染成本。

黑底亮度检测仍有单帧查询上限。达到上限会报错停止，不会返回不完整范围。复杂黑底软边建议在源合成中先去黑底，然后使用透明度检测。

## 帧数比指定格子数少

每个格子必须对应一个不同的源帧。所选范围源帧不足或达到 1024 帧输出上限时，会建议较小的完整网格，不重复帧填格。指定图集方式保持输入宽高；指定行列方式根据建议网格重新计算图集尺寸。

## 帧编号与时间轴显示不一致

工具使用从合成内部时间 0 开始的源帧编号，不受时间轴显示起始帧影响。自定义范围两端包含，导出 JSON 同时记录内部时间和源帧编号。合成结束时刻不构成额外的一帧。

## 无缝循环、去黑底或透明度不符合预期

工具负责检测、排列、抽帧和输出，不会替素材制作无缝循环，也不会自动去黑底。应先在源合成完成这些处理。检测阈值仅用于计算裁剪范围，不会将输出像素自动清零或去噪。
