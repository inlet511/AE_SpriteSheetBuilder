# 详细使用说明 — Sprite Sheet Builder 1.8

## 安装

关闭旧面板。解压 1.8 压缩包，在 AE 中选择「文件 → 脚本 → 运行脚本文件」，打开 SpriteSheetBuilder.jsx。需要停靠时，将 JSX 放入 Support Files/Scripts/ScriptUI Panels，重启后从「窗口」打开。标题应显示 1.8。

## 流程

读取素材合成 → ② 内容范围检测 → ③ 尺寸与排列 → ④ 生成与导出。

检测支持逐帧、按源帧间隔抽样、指定单帧。默认忽略透明度不超过 1% 的像素，四周保留 4 像素。检测工作区、检测间隔等参数独立于输出设置，修改尺寸、行列或抽取范围不要求重新检测。抽帧和单帧检测只能代表被检测帧，覆盖完整运动范围应使用逐帧检测。

透明度检测先用 AE 原生通道转换和阈值效果制作临时检测遮罩，再查找边界，避免旧版对淡烟边缘的大量递归采样。源合成与导出内容不添加这些效果。阈值精度受工程位深影响。每帧之间将控制权交回 AE，显示进度和耗时；「取消检测」在当前帧求值结束后生效，不能中断 AE 正在渲染的单帧。完成、取消或失败都会清理临时检测合成。关闭浮动面板也会取消。

黑底亮度检测只判断边界，不去黑底。目前仍采用逐区域精确查询，但限制单帧查询次数，达到上限会停止并说明原因，不会使用不完整边界。复杂黑底软边建议先完成去黑底，再使用透明度检测。

## 尺寸与排列

「选择内容尺寸计算基准」提供「素材原始尺寸」与「采用内容范围」。后者使用所有检测帧的共同范围，同一裁剪区域用于每个输出帧，保持位置稳定。缩放百分比相对于当前基准。例如内容范围 188×308，50% 得到 94×154。内容等比放入指定单帧区域。

所有排列统一使用无空格铺满：每格一个不同的源帧，格子等大，内容居中，余量均匀变成透明间隙。不再提供「紧密排列」。

| 排列方式 | 输入 | 计算结果 |
| --- | --- | --- |
| 左侧：指定行列数 | 列数、行数；可选最终宽高扩大到 2 的 N 次方 | 帧数为列×行，尺寸由单帧大小和行列得出；扩大后的余量均匀加入各格 |
| 右侧：按指定图集尺寸排布 | 图集宽度、高度 | 严格保持指定宽高，在单帧能放下且源帧足够的前提下，选择有效帧最多的完整网格，自动均分余量 |

例如单帧 256×256、图集 2048×1696，源帧足够时排列为 8×6、48 帧。每格宽 256、高 282.6667，垂直间隙约 26.6667，每侧约 13.3333 像素。最终图集仍为 **2048×1696**，不会截短到 1692。显示数值四舍五入到四位小数，实际计算与导出使用完整精度。

每格两侧各留一半间隙，因此首末边缘的留白是相邻内容间隙的一半。格子完整覆盖图集，内容区域不拉伸。尺寸不能整除行列时允许小数像素坐标，与 UE 按行列等分的采样方式一致。

若指定格子数多于可用源帧或 1024 帧上限，插件会在指定行列范围内推荐较小的完整网格并明确提示。不会重复源帧或留下空格。指定行列方式下的最终图集按建议行列重新计算；指定图集方式始终保持输入尺寸。

## 抽取范围与预计算

默认从整个合成均匀抽取，也可选择工作区或自定义起止源帧，编号从 0 开始且两端包含。帧数由排列决定。多帧输出包含所选范围首末实际源帧，源帧间隔最多相差 1；一帧时取范围首帧。例如 25 fps、10 秒素材有效帧是 0～249。

参数修改后，离开输入框或按回车会自动更新预览；检测完成后也会自动计算一次。排列示意在所有参数的最下方，右侧纵向滚动条可查看。固定底部的「③ 预计算排列」按钮重新计算、滚动到结果，并在底部显示更新时间和结果摘要；无效参数会明确显示错误。

绿色数字是有效帧数，蓝色数字是行列和最终尺寸，黄色文字是间隙与每侧留白。示意图中蓝色为单帧内容区域，深色为透明间隙。这是排列示意，不是烟雾画面预览。

限制：单帧宽高 16～4096，每个方向最多 64 格，图集每边不超过 8192，最多 1024 个不同输出帧。

## 生成与导出

「生成图集合成」可先在 AE 内检查；「生成并导出透明 PNG」输出 PNG 和同名 JSON。脚本查找并验证已有 PNG 输出模板，要求 PNG / RGB + Alpha / Straight，并关闭缩放和裁剪。若没有合适模板，需创建一次后填入备用模板名称。导出需允许脚本写入文件。

导出保留源合成 Alpha；不透明黑底需事先去除。其他待渲染队列项在导出期间暂时停用，结束或失败后恢复。JSON 包括行列、间隙、共同裁剪范围、逐帧时间和源帧编号。UE 的 Sub Image Size 使用最终列数和行数，Sub Image Index 播放 0～有效帧数减 1。无缝循环仍需在源动画中制作。

## 验证

测试覆盖精确图集尺寸、最大帧数、无空格、UE 等分中心坐标、均匀抽帧、独立内容检测、异步调度/取消重试、预览位置/按钮反馈以及导出模拟。Windows AE 25.6.4 中已验证原生阈值遮罩、边界检测和透明单帧 PNG 输出。不同平台、面板布局和完整工作流仍需实机验收。

淡出帧出现白点、透明输出模板缺失等问题，参见[常见问题](TROUBLESHOOTING.md)。
