# AE Sprite Sheet Builder

在 After Effects 内检测素材内容范围，预计算均匀排列，并导出适合 Unreal Engine / Niagara 使用的透明 Sprite Sheet。

**当前版本：1.8.0 · 中文 ScriptUI 面板 · 单文件 ExtendScript**

## 功能

- 读取当前合成尺寸、帧率与时长。
- 独立内容检测：逐帧、间隔抽帧或指定单帧；支持工作区、阈值、安全余量与取消。
- 以素材原始尺寸或共同内容范围为基准设置单帧尺寸和缩放。
- 指定行列数，或严格按指定图集宽高排布；格子等大、无空格、间隙自动均分。
- 按排列得到的帧数，从完整合成、工作区或自定义范围均匀抽取。
- 彩色排列示意、尺寸与间隙预计算、纵向滚动条。
- 生成 AE 图集合成，或导出 **PNG + Alpha 与 JSON 元数据**。

## 运行环境

| 用途 | 要求 |
| --- | --- |
| 使用工具 | Adobe After Effects 2025；已在 Windows 的 AE 25.6.4 进行原生检测与透明单帧渲染检查 |
| 内容检测 | 方形像素合成；建议 16 bpc 工程处理柔和透明烟雾 |
| 导出 PNG | PNG / RGB + Alpha / Straight 输出模板，并允许脚本写入文件 |
| 开发测试 | Node.js 22 或以上，无第三方 npm 依赖 |
| 构建安装包 | Windows PowerShell 或 PowerShell 7 |

其他 AE 版本和 macOS 尚未实机验证。普通用户不需要安装 Node.js，也不需要 PowerShell 辅助检测程序。

## 快速安装

下载发行安装包并解压，或者直接下载本仓库根目录的 [SpriteSheetBuilder.jsx](SpriteSheetBuilder.jsx)。

**临时运行：** AE 中选择「文件 → 脚本 → 运行脚本文件」，打开该 JSX。

**停靠面板：** 将该 JSX 放入 AE 安装目录下的 `Scripts/ScriptUI Panels` 文件夹，重启 AE，再从「窗口」菜单打开。Windows 通常位于 `Adobe After Effects 2025/Support Files/Scripts/ScriptUI Panels`。更新前关闭旧面板并替换旧 JSX。

## 快速使用

1. 打开已经完成裁剪、透明度和循环处理的源合成，点击 **① 读取当前素材合成**。
2. 在 **② 内容范围检测** 中设置检测方式并检测；例如每隔 10 个源帧检测一次。
3. 在 **③ 尺寸与排列** 中选择尺寸基准、缩放和排列方式。
4. 设置输出抽取范围。插件由排列确定帧数，并在该范围均匀抽取。
5. 检查参数下方的排列示意。点击预计算按钮会跳转到结果并显示更新时间。
6. 在 **④ 生成与导出** 中生成图集合成，或导出透明 PNG 和 JSON。

检测设置与输出设置独立。调整行列、图集尺寸或抽取范围不会要求重新检测；抽样检测只能代表抽到的帧，需要完整运动范围时使用逐帧检测。

### 两种排列方式

| 方式 | 控制参数 | 结果 |
| --- | --- | --- |
| 指定行列数 | 行列数、单帧大小；可选扩展到 2 的 N 次方 | 计算最终图集宽高，扩展空间均分到各格 |
| 按指定图集尺寸排布 | 图集宽高、单帧大小 | 保持输入尺寸，寻找容纳最多不同源帧的完整网格，自动均分间隙 |

例如：单帧 **256×256**，图集 **2048×1696**，源帧足够时得到 **8 列 × 6 行 / 48 帧**。每格高约 282.6667 px，垂直间隙约 26.6667 px，最终图集仍为 **2048×1696**。

所有格子都包含有效帧，格子尺寸完全相同。不能整除时使用小数像素位置，保持 UE 按行列等分采样一致。内容保持原设定大小，不会拉伸填格。

## 输出与 UE

一次导出生成同名 PNG 和 JSON，记录图集尺寸、行列、逐帧源时间、共同裁剪范围、间隙和播放参数。

- UE / Niagara 的 `Sub Image Size` 使用最终列数和行数。
- `Sub Image Index` 播放 `0` 到 `frameCount - 1`。
- 每格顺序为从左到右、从上到下。
- 导出保留源 Alpha；无缝循环和去黑底应先在源合成制作。

JSON 字段包括 `imageWidth`、`imageHeight`、`columns`、`rows`、`frameCount`、`cellWidth`、`cellHeight`、`gapX`、`gapY`、`sourceCrop`、`samples` 和 `ueSubImageSize`。

```text

├── README.md
├── CHANGELOG.md

├── docs/                    # 使用、排错与开发文档
```

开发者运行 `npm test` 检查逻辑，Windows 下运行 `npm run build` 生成最新安装包和源码包到 `dist/`。无需安装 npm 依赖。模拟测试不替代实际 AE 界面与渲染验收。

本目录可作为独立 GitHub 仓库根目录提交。仅维护当前版本源码，构建产物由脚本生成并被 Git 忽略。

## 已知限制

单帧宽高 16～4096 px，每方向最多 64 格，图集每边不超过 8192 px，最多 1024 个不同输出帧。源帧不够填满指定网格时会建议较小网格。检测取消在当前帧求值完成后生效。黑底检测只判断范围，不去黑底；复杂软边达到查询上限时需要先处理源合成。
